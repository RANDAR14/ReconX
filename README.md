# ReconX

Automated reconnaissance tool for penetration testing engagements. Performs Nmap-based service discovery and saves organized, timestamped scan reports.

## Features
- Automated Nmap scan (service version detection + default scripts)
- Organized output in `results/` folder with timestamps
- Quick open-ports summary after each scan

## Usage
```bash
chmod +x recon.sh
./recon.sh
```
Enter target IP or domain when prompted.

## Requirements
- Nmap
- Bash (Linux/Kali)
